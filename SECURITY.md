# Security policy

Do not open a public issue for a vulnerability.

Report security issues through the **Security** tab of the affected public repository, using **Report a vulnerability**. If that is unavailable, contact an organization owner privately. Do not open a public issue.

Include:

- affected repository and version or commit;
- a description of the issue;
- reproduction steps or a proof of concept;
- impact assessment;
- any suggested mitigation.

We will acknowledge within two business days, triage within five business days, and coordinate disclosure after a fix is available. Do not test against production instances without written permission.
